# Site photos

Drop real photos in this folder and the site picks them up **automatically at the
next build** — no code changes needed:

| File | Where it appears | Suggested shot |
| --- | --- | --- |
| `hero.jpg` | Homepage hero (right panel) | Team at work, or a spotless finished space. Landscape, ~1600×1280px. |
| `about.jpg` | About page (left square) | The team together, or equipment/uniforms. Square crop, ~1200×1200px. |

Until these files exist, the site renders branded placeholder panels instead —
nothing fake is shown.

Tips:
- Use real photos of your own team and work, not stock images.
- Keep files under ~400 KB (Next.js optimizes them further).
- JPG format, well lit, no heavy filters.
